# Qwen-Image-2.1

The image generation and edit routes use the native `QwenImage21Pipeline` from the [official Diffusers integration](https://github.com/huggingface/diffusers/pull/14804), pinned to `8d3c30bfda9b511c00992f40cff4170a5502814d`. The API requirements include `api/requirements-qwen-image.txt` to enable this provider. The existing Transformers pin is 5.19.0.dev0, satisfying the official >=5.17 requirement.

The [official model](https://huggingface.co/Qwen/Qwen-Image-2.1) is pinned to `d26bb61231c349cf6b7896fa83353113880e1ba3`. Its approximately 33.1 GB bundle includes the processor, Qwen3-VL text encoder, image transformer, VAE and scheduler. Generation only loads Kadan's completed download; it never downloads weights implicitly or executes checkpoint Python code. The research license permits research/evaluation only; commercial use requires a separate license. Download acknowledgement is not a commercial grant.

Kadan reserves host memory and the selected device budget through its shared resource manager before loading. Large GPUs hold the complete pipeline; smaller devices use sequential CPU offload and VAE tiling under the same lease. `KADAN_IMAGE_DEVICE=cpu` enables CPU execution; otherwise the provider uses `cuda:${KADAN_GPU:-0}`. RAM estimates include checkpoint bytes plus headroom; they are admission estimates, not measured peak-memory guarantees. Requests serialize images to avoid multiplying activation memory. There is no claim of 3090 throughput or a minimum supported GPU.

Generation uses the checkpoint's native aspect sizes and 40 denoising steps. Editing conditions on the uploaded image and prompt. The pipeline has no edit-strength parameter, so the prior nonfunctional strength slider is removed instead of silently ignoring it. PNG output preserves alpha. Results publish atomically into `KADAN_MEDIA_DIR/images` (default `~/.local/share/kadan/media/images`), with history and PNG routes. Disconnects request cooperative cancellation at denoising boundaries; ownership remains held until native cleanup completes. A request can take time to stop while a native kernel or model load is running.

Validation uses tiny synthetic images, fake pipeline modules and HTTP fixtures to check arguments, ownership, cancellation, failure/retry, PNG publication and rendering. No model weights were downloaded; actual model/GPU quality, peak memory and performance tests were not run.
