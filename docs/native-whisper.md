# Native Whisper engine

The engine accepts mono 16-bit PCM WAV data URLs at 16 kHz. The existing recording control records locally and converts its recording to this input on Submit. No URL fetching or server file references are allowed. The response preserves `raw_text`, detected language and the canonical model name; silence is a valid empty transcript. S1 formatting is a separate dependency.

Checkpoint integrations are additive JSON registrations in `api/services/whisper_checkpoints/`. Each independently reviewed checkpoint PR enables one official model; the engine alone enables none. `large` and `turbo` resolve to `large-v3` and `large-v3-turbo` and never create duplicate storage. The immutable SHA256/URL registry comes from the [official OpenAI source](https://github.com/openai/whisper/blob/main/whisper/__init__.py). Code and weights are MIT licensed.

Native inference uses `openai-whisper==20250625` and receives an already completed, SHA256-verified local `.pt` file. It never calls the library with a downloadable model alias. The shared downloader must implement `get_checkpoint('whisper-{name}') -> (entry, directory)` with `{name}.pt` inside the directory. The engine incorporates the shared downloader dependency and adds HEAD-size discovery, SHA256 verification and atomic publication for single-file checkpoints. Exact Azure object sizes could not be independently verified because this execution environment returns HTTP403 to metadata HEAD requests; no guessed exact sizes are supplied.

`KADAN_WHISPER_DEVICE` chooses `cpu` (default) or one `cuda:<index>`. Kadan reserves host and device memory before audio decoding/loading, protects allocations for the whole native call, and frees allocations before releasing ownership. Each request unloads after completion; this first engine does not retain idle Whisper weights. Memory reservations are conservative admission estimates, not measured peaks. Native Whisper is monolithic: a disconnected HTTP caller does not terminate a running native call; its reservation remains held until the call ends and cleanup completes.

Validation uses small synthetic PCM and injected native factories: real weights, GPU execution, transcription accuracy and performance are not tested. No weight downloads or dependency installation were performed. The original package can decode file paths with ffmpeg, but this integration supplies PCM arrays and requires no ffmpeg installation.
