# Folders and pins

Tsuchi stores the folders that organize Kadan's [Space](../kadan/space.md). A folder has a name and can hold other folders, Space documents, slide decks, files and images belonging to the same agent. Folders appear in Tsuchi's **Folders** view and as parent choices under **Details**; a folder has no text or attachments of its own.

A folder cannot be placed inside a Space document or inside itself. Memories, personas and conversations cannot be placed in folders. Tsuchi's own file editor does not move files between folders; Kadan's Space does.

Items can be pinned in Kadan's Space. Editing an item in Tsuchi keeps its pin and its folder.

A folder that still holds active items cannot be moved to [trash](trash.md) from Tsuchi; move or trash its contents first. A document or deck inside a trashed folder can only be [restored](restore.md) after the folder. A file whose folder is still in trash is restored to the top level instead.
