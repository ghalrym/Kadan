# Resource copies

In Tsuchi, **Make a copy** starts a separate unsaved draft from the current edits of a saved persona, memory, Space or slide deck. It keeps the parent, tags, sources, attachments and slides, reusing linked files in the same agent. A Space copy includes only its document, without children; a project-tagged Space keeps its project tags.

Choose a useful title and select **Create** to save the copy. Failed creation keeps the draft available to correct and retry; closing with unsaved changes asks whether to discard them. Copying leaves the original and its history unchanged and does not select a persona in Kadan.

The action is unavailable in History, Trash, conversations and new drafts, and is disabled during a pending save or message operation.
