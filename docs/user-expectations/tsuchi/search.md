# Search

Tsuchi's **Search all resources** searches active personas, memories, Spaces, slide decks and conversations in the selected agent's namespace. Collection searches narrow results to that resource type. Trashed records and other agents' content are excluded.

Resource search matches stored words and word beginnings in titles, Markdown, tags, sources, slide text and notes, and conversation messages. Multiple search words must all match somewhere in the record. Results are ordered by recent updates rather than relevance. **Previous** and **Next** reveal additional result pages.

Images and attachments have separate library searches covering titles, filenames, tags and source links. They are not included as independent results in the global resource search. Search does not extract PDF text, transcribe recordings, recognize image contents or find related meanings without matching words.

A loading failure must remain distinguishable from no matches. **Refresh data** or submitting another search checks saved content again. Unsaved drafts are not searchable. Opening a result does not attach it to chat or make an agent recall it.
