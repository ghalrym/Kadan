# Overview and activity

Tsuchi's Overview summarizes the selected agent's storage. Resource and file counts exclude trash unless labelled otherwise. File storage includes retained bytes in trash, while **Database · all namespaces** reports the shared database size. Trashing content does not reclaim its bytes.

The Files total includes images; Trash counts both resources and files. Collection cards open the corresponding lists. **Export namespace** downloads that agent's portable archive. See [Export and backup](../../../services/tsuchi/README.md#export-and-backup) for what it includes and how a complete backup differs.

Overview and Activity show recent storage changes. They are not an agent's reasoning, an inference queue or a complete audit history. Older changes can disappear from these bounded lists.

Both pages refresh periodically. **Refresh data** requests an immediate update. Errors must remain visible, and switching agents changes the records shown while the shared database-size statistic remains global.

See [Storage monitoring](../../architecture/tsuchi/monitoring.md) for count scope and retention.
