# Slide decks

Tsuchi stores slide decks, which users create and edit in Kadan's [Space](../kadan/space.md). Each deck uses a fixed widescreen canvas and supports up to 100 slides. Users can add, delete and reorder slides, edit titles, Markdown text and speaker notes, and choose title, text, split or image layouts.

Each slide can use one image from that agent's image library. Removing the image from a slide leaves the stored image available. Uploading and generating images are separate operations.

Changes persist only after saving. Failed saves and conflicting edits must remain visible. Saved decks support revisions and trash/restore.

[Backups](export.md) retain decks as editable JSON alongside their image files. Decks have no freeform element positioning, animations, slideshow player or PowerPoint import/export. A preview does not establish compatibility with another presentation application.

See [Revisions](revisions.md) and [Export](export.md).
