# Home

Kadan Server's **Home** answers "is Kadan ready?" at a glance.

- A summary line says **Everything is ready**, **Getting ready** (while models download), **Some abilities need setting up**, or **Kadan can't reach its storage**, with a sentence on what to do next. It checks again every few seconds.
- **Connect Kadan** shows this server's address with **Copy**, and explains where to paste it in the Kadan app.
- **What your agent can do** lists each ability (Chat & thinking, Images, Dictation, Reading aloud) with a plain status: Ready, Needs download, Waiting to download, Downloading with a percentage, Download stopped, or Not running. Abilities that need a download offer a button that opens [AI models](ai-models.md).
- The agent card shows the agent's pet, name, how many memories it has and how much it has saved. Choosing it opens [Your agent](your-agent.md).
- **Memory in use** shows computer and graphics card memory. It includes everything running on the computer, not only Kadan, and does not prove a model will fit.

If the server cannot be reached, Home says so instead of showing stale readiness.
