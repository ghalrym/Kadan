# Activity

Kadan Server's **Activity** shows what the AI models on this computer have worked on recently, newest first, and refreshes every few seconds.

- Each row shows the time, what it was (Chat reply, Image, Dictation, Reading aloud or Decision), how long it took and the result: **Done**, **Couldn't run** or **Failed**.
- **Everything** and one filter per kind narrow the list. Long histories split into pages with **Newer** and **Older**.
- Choosing a row shows its details: the model, how quickly it started answering, its speed and length where known, the request ID, and the request and response text the server kept.
- The history is short and lives only while the server runs; restarting clears it, and old entries drop off as new ones arrive. Activity does not cancel or retry work.
