# Your agent

Kadan Server's **Your agent** section, shown in the sidebar with the agent's name and pet, gathers what the agent has stored. Tabs across the top switch between:

## Memories

Lists what the agent chose to remember, newest first, with search. Opening a memory lets users fix its title and text and **Save**; changes take effect on the agent's next reply. **Forget…** asks for confirmation, then moves the memory to Trash, where it can be restored. If the memory changed elsewhere since it was opened, saving fails, keeps the user's text, and offers **Load the saved version**. See [Agent memory](../kadan/memories.md).

## Persona

Shows the agent's persona for editing, with **Undo changes** and **Save persona**. **Earlier versions** lists every saved version; **View** previews one and **Restore** saves it as the newest version without erasing history. A failed save keeps the text and offers **Reload**. See [Personas](../kadan/personas.md).

## Chat history

Shows the user's chat with the agent, read-only, newest messages last, with **Show earlier messages** for long histories. Chatting continues in the Kadan app.

## Trash

Lists removed memories, pages, slides, chats and files, newest first, with **Restore**. Items in trash keep their contents and files and are hidden from the agent. Restoring can fail when something it depends on is also in trash; the error explains what to restore first. Kadan Server has no way to permanently empty trash. See [Trash](../tsuchi/trash.md) and [Restore](../tsuchi/restore.md).

## Backup

**Download backup** saves a copy of everything the agent has stored. Downloading it changes nothing in Kadan. See [Export](../tsuchi/export.md).
