# Reading chat

Kadan opens each agent's conversation at its latest message. While the reader stays near the bottom, incoming messages and typing activity keep the latest conversation content in view. Scrolling away from the bottom pauses that automatic following and keeps the currently revealed history available as messages arrive.

**Jump to latest** returns to the bottom and resumes following. Scrolling back near the bottom also resumes following. The control does not count unread messages or indicate whether a message has been read.

Sending a message or saving a note returns to the latest content unless a [Find](finding-chat-text.md) query is active. Find navigation keeps control of the reading position. **Close find and jump to latest** clears the search and selected match before returning to the bottom; closing Find alone leaves the current reading position in place.

Changing agents or conversations resets this position and opens at the latest message. The reading position is local to the open view and is not saved in the conversation.
