# Navigation and the Agent page

Kadan's layout follows coding-assistant apps such as T3 Code and Codex: a sidebar on the left and the selected page filling the rest of the window, with no title bar above it. On narrow screens the sidebar opens from the menu button in the top-left corner.

## Sidebar

From top to bottom, the sidebar offers:

- **Chat** opens the agent's single ever-persistent conversation thread.
- **Space** opens the [Space](space.md) library of pages, slides and files.
- **Plugins** opens the [Plugins](plugins.md) page.
- The agent's name and pet open the **Agent page**.
- Directly below the agent link, **Server settings** (in the standalone Kadan app) shows the connected server address and connection status and lets you switch servers, alongside a refresh button that reloads server status, the agent and its chats. Tsuchi and Hikari management live in **Kadan Server**, not inside the Kadan client app.

Lists in the sidebar reflect what Kadan last loaded. Changes made on Tsuchi's pages appear after returning to Kadan or refreshing.

## Agent page

The Agent page gathers settings for the agent itself:

- Its pet, with **Edit pet** to [change it](pets.md), **Persona** to [edit its persona](personas.md), and **Rename** to [rename the agent](renaming-agents.md).
- **Memories**, where users can search, read and [correct](memories.md) what the agent chose to remember.
- **Runner**, where **Manage runner** opens [runner assignment](runner-availability.md).
- **Delete agent**, which asks you to type `<agent name> Delete` before permanently removing the agent, all its memories, chat history, persona, Space items, and pets so you can start fresh with a new default agent.

See [Agent conversations](agent-conversations.md) for how chats behave.
