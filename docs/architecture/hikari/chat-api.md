# Chat API

`POST /v1/chat/completions` accepts system, user, assistant and tool messages. A turn can use Hikari’s `text` field, a `content` string, or ordered text and image parts. Tool results identify the assistant call they answer. The native renderer tokenizes role and channel markers separately from authored text, so quoting a marker preserves its literal meaning.

Both JSON response envelopes expose complete calls in `tool_calls`. The function arguments are a JSON object encoded as a string. Streaming sends assistant text in `delta.content` and complete indexed calls in `delta.tool_calls`. The terminal reason is `stop`, `tool_calls` or `length`, followed by `[DONE]`. An incomplete native tool invocation cannot produce an executable call.

The endpoint uses the configured local Inkling 2 Mini checkpoint (`inkling-2-mini-iq4-nl` by default, or `inkling-2-mini-q8-0` via `HIKARI_LLM_QUANT`, and the abliterated `inkling-2-mini-abliterated-*` variants via `HIKARI_LLM_ABLITERATED=true`), whether `model` is supplied or omitted, and rejects unsupported model IDs. Callers may also pass an optional `weight_variant` (`"base"` or `"abliterated"`) on `POST /v1/chat/completions` (and `POST /v1/decisions`) to select the standard or abliterated Inkling 2 Mini weights at the configured precision without changing the default; supplying both `model` and a conflicting `weight_variant` fails validation (`422`), and requesting a variant whose local checkpoint is not downloaded fails cleanly rather than substituting the other variant. Kadan's runner (`services/kadan/kadan/runner/agent_inference.py`) maps `task_class` (`"persona_chat"` -> `"abliterated"`, `"harness"` -> `"base"`) or explicit `weight_variant` onto this field. When a [subscription provider](subscriptions.md) serves language, the same request (including multimodal screenshots) is answered by that subscription instead. Structured tool definitions and tool history follow [the language worker contract](worker-llm.md). Unknown fields, unsupported roles and malformed tool or image payloads fail validation. Before streaming starts, errors use FastAPI's HTTP status and `detail` body; stream failures use an `error` event followed by `[DONE]`, without a successful terminal choice.

## Playground state and retry

The browser sends its full current conversation and receives SSE text. It retains messages and drafts only in page memory. This keeps direct inference separate from Kadan's durable run ownership. See the user expectations for [the chat playground](../../user-expectations/hikari/chat-playground.md).

Hikari Chat sends the active Inkling 2 Mini checkpoint (or lets Hikari route to the configured language subscription) for every turn, retry and new conversation. That uses the native `hikari-worker-llm` Strata worker and its user-approved download when local.

A malformed or incomplete stream is a failed turn. Cancel aborts the browser request, discards partial assistant text and retains the user turn for retry. Retry performs another inference rather than restoring an earlier response. Native cleanup can outlast browser cancellation. Model/context selection and memory admission remain in [Model lifecycle](model-lifecycle.md) and [Inference architecture](inference.md).
