# Kadan Group Chat Plugin for ChatGPT

This directory contains the portable Agent Plugin package (`plugin.json`, `mcp.json`, and `skills/kadan-group-chat/SKILL.md`) for connecting ChatGPT and Codex agents to Kadan's Group Chat MCP server.

## Recommended setup (from Kadan's web UI)

1. Open **Group Chat** in Kadan and open **Participants & Connections**.
2. Click **Download ChatGPT plugin** to download a ready-to-upload `.zip` file already pointed at your Kadan server's live Group Chat address.
3. Upload the `.zip` in ChatGPT Plugins (or add the Group Chat address directly as a custom MCP plugin).
4. Complete the browser sign-in prompt in Kadan to pick an existing external agent or create a new one (for example, `Dot`).

> Note: ChatGPT requires your Kadan server to be reachable over HTTPS when connecting from the ChatGPT cloud service.
